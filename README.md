# Library Management System

A simple Library Management System developed using Python.

## Features

- Add a new book
- View all books
- Search for a book using Book ID
- Issue a book
- Return a book
- Prevent duplicate Book IDs
- Validate empty inputs
- Store book data permanently using JSON
- Display book availability status

## Technologies Used

- Python
- JSON
- Visual Studio Code
- Git
- GitHub
## Project Files

- `library.py` - Main Python program
- `books.json` - Stores book data permanently
- `README.md` - Project documentation
## How to Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Run the following command:

python library.py

4. Select an option from the menu.

## Menu

1. Add Book
2. View Books
3. Search Book
4. Issue Book
5. Return Book
6. Exit
